# M2.5 — OKF Conformance for the Profile Wiki: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the story markdown files the original and the JSON a rebuilt cache: `create_story` writes one `experience/story-NNN.md` with YAML frontmatter, `compile_profile` reads every story file and rewrites only `index.md` and `compiled_profile.json`, `submit_keywords` reads `type` and `tags` from frontmatter instead of regex-scraping prose, and a one-time, idempotent migration moves the 14 existing stories out of `accomplishments.json`.

**Architecture:** Two small new pieces. `callback/wiki.py` gains generic OKF page helpers (`split_frontmatter`, `join_frontmatter`). A new `callback/repository/stories.py` owns the story ⇄ page mapping (`story_to_page`, `story_from_page`), the file-backed store (`save_story`, `list_stories`), and the migration (`migrate_legacy_stories`). `AccomplishmentsStore` shrinks to the onboard text. `wikirenderer.py` renders only `index.md`. `profile_nodes.py` and `server.py` switch to the new functions. `CreatedStory` and `CompiledProfile` keep their shapes, so `compiled_profile.json`, `get_wiki_pages`, page ids, and index links do not change.

**Tech Stack:** Python 3.12, PyYAML (declared as a runtime dependency), pydantic 2, LangGraph profile graph, pytest, uv.

**Spec:** `INTENT.md` §"The profile is the source of truth" and §"M2.5 — OKF conformance for the profile wiki" (items 1–4, "Out of scope", "Done when"); the data-flow diagram at https://claude.ai/code/artifact/49338a2d-dca0-4ab7-922a-0ebcd918c0b2 ("Proposed" half); `DECISIONS.md` Q1.

- Judgement rules: imports at the top of the file; every `except` re-raises, raises with context, or logs at WARNING+; catch narrowly; every fallback logs that it was taken and why. A user reading `server.log` must be able to tell a migrated story from a freshly written one and a skipped file from a parsed one.
- **Page format (exact).** A story page is:
  ```
  ---
  type: story            # or: project
  title: data pipelines  # == CreatedStory.primary_skill
  job_title: Software Development Engineer I
  tags:
  - Python
  - AWS
  story_type: SBI
  timestamp: '2026-09-06T21:15:00+00:00'
  ---
  # data pipelines

  **Situation:** …

  **Behavior:** …

  **Impact:** …
  ```
  `type` is `project` when `job_title == "Project"` (case-sensitive, matching today's `_is_project_story` regex), else `story`. The three body paragraphs are located by their `**Situation:**` / `**Behavior:**` / `**Impact:**` labels; text before the first label (the `# title` line) and blank lines are ignored. Frontmatter is written with `yaml.safe_dump(meta, sort_keys=False, allow_unicode=True)` and read with `yaml.safe_load`. The only required frontmatter key is `type`; a page missing `type` is not a story.
- **`CreatedStory` and `CompiledProfile` do not change.** `id` comes from the filename (`experience/story-007.md` → `story-007`); `timestamp` lives only in frontmatter.
- **Compile never writes a story file.** `compile_profile` writes `index.md` and `compiled_profile.json` only. `create_story` writes exactly one story file. The migration is the only code path that writes a story file from JSON, and it writes only files that are missing or have no frontmatter.
- **`index.md` output is byte-identical to today's** for the same stories and tags (`_index_content` is untouched; stories are listed in id order, which is the order `accomplishments.json` held them in).
- Public MCP tools keep their signatures and envelopes. `get_wiki_pages` returns page content as stored (frontmatter included).
- Do not touch `sections.json`, `evals/`, scoring, tailor instructions, or the extraction protocol.
- Rulings already made (do not re-litigate; record deviations in the task report):
  - **PyYAML is declared** in `pyproject.toml` and the M4 ceiling in `tests/test_dependencies.py` moves from 11 to 12 with a one-line reason. INTENT said "already installed under langchain"; importing an undeclared transitive package is the thing M4 just stopped doing.
  - **`story_type` is kept in frontmatter** even though INTENT's field list omits it: `CreatedStory` requires it and the host passes it to `create_story`. Without it the file could not be read back losslessly.
  - **`title` is `primary_skill`**, not a free-form headline. Today's H1 is `{primary_skill} — {story_type.title()}` and the project-candidate "name" is that H1 with the suffix stripped, i.e. `primary_skill`. Keeping `title == primary_skill` keeps `submit_keywords` output identical.
  - **Migration runs automatically and idempotently** at the start of the `onboard` and `compile_profile` nodes (`migrate_legacy_stories(label)`), not as a CLI command: `cli.py` is already over budget and M5 shrinks it. Every migrated file is logged. The migration stamps `timestamp` with the migration time, because the JSON never held one.
  - **Unreadable story pages are skipped with a WARNING and reported**, not fatal: `list_stories` returns `(stories, warnings)` and `compile_profile` surfaces the warnings in `intake.skill_coverage_warnings` next to the existing lint warnings.
```python
_FENCE = "---\n"


class WikiPageError(ValueError):
    """A page's YAML frontmatter is malformed."""


def split_frontmatter(content: str) -> tuple[dict, str]:
    """Split an OKF page into (frontmatter mapping, markdown body).

    A page without a leading fence has no frontmatter: returns ({}, content).
    """
    if not content.startswith(_FENCE):
        return {}, content
    end = content.find("\n" + _FENCE, len(_FENCE) - 1)
    if end < 0:
        raise WikiPageError("frontmatter has no closing '---' fence")
    raw = content[len(_FENCE) : end + 1]
    body = content[end + 1 + len(_FENCE) :]
    try:
        meta = yaml.safe_load(raw)
    except yaml.YAMLError as exc:
        raise WikiPageError(f"frontmatter is not valid YAML: {exc}") from exc
    if meta is None:
        meta = {}
    if not isinstance(meta, dict):
        raise WikiPageError(f"frontmatter must be a mapping, got {type(meta).__name__}")
    return meta, body


def join_frontmatter(meta: dict, body: str) -> str:
    header = yaml.safe_dump(meta, sort_keys=False, allow_unicode=True)
    return f"{_FENCE}{header}{_FENCE}{body}"
```

(`end` search starts at index 3 so a body that is itself empty still finds the closing fence on the very next line.) Add `"pyyaml>=6.0",` to `pyproject.toml` dependencies (alphabetical, after `pydantic`); run `uv sync`.

```python
"""Stories live as OKF markdown pages under <wiki>/<label>/experience/story-NNN.md.

The page is the original. JSON caches (compiled_profile.json) are rebuilt from
these files and never the other way round.
"""

from __future__ import annotations

import logging
import re
from datetime import UTC, datetime

from callback.state import CreatedStory
from callback.wiki import WikiPageError, WikiStore, join_frontmatter, split_frontmatter

logger = logging.getLogger(__name__)

STORY_TYPES = ("story", "project")
_PROJECT_JOB_TITLE = "Project"
_STORY_FILE_RE = re.compile(r"^story-(\d{3,})\.md$")
_LABELS = ("Situation", "Behavior", "Impact")
_PARAGRAPH_RE = re.compile(r"^\*\*(Situation|Behavior|Impact):\*\*\s*(.*?)\s*(?=^\*\*(?:Situation|Behavior|Impact):\*\*|\Z)", re.M | re.S)


def story_page_id(story_id: str) -> str:
    return f"experience/{story_id}.md"


def _story_id_from_page_id(page_id: str) -> str:
    return page_id.rsplit("/", 1)[-1].removesuffix(".md")


def story_to_page(story: CreatedStory, timestamp: str) -> str:
    meta = {
        "type": "project" if story.job_title == _PROJECT_JOB_TITLE else "story",
        "title": story.primary_skill,
        "job_title": story.job_title,
        "tags": list(story.skills),
        "story_type": story.story_type,
        "timestamp": timestamp,
    }
    body = (
        f"# {story.primary_skill}\n\n"
        f"**Situation:** {story.situation}\n\n"
        f"**Behavior:** {story.behavior}\n\n"
        f"**Impact:** {story.impact}\n"
    )
    return join_frontmatter(meta, body)


def _body_paragraphs(page_id: str, body: str) -> dict[str, str]:
    found = {label: text for label, text in _PARAGRAPH_RE.findall(body)}
    for label in _LABELS:
        if label not in found:
            logger.warning("%s: no '**%s:**' paragraph in body; stored as empty", page_id, label)
            found[label] = ""
    return found


def story_from_page(page_id: str, content: str) -> CreatedStory:
    """Rebuild a CreatedStory from a page. Raises WikiPageError when it is not a story."""
    meta, body = split_frontmatter(content)
    page_type = meta.get("type")
    if page_type not in STORY_TYPES:
        raise WikiPageError("frontmatter has no 'type'" if page_type is None else f"type {page_type!r} is not a story")
    paragraphs = _body_paragraphs(page_id, body)
    tags = meta.get("tags") or []
    if not isinstance(tags, list):
        raise WikiPageError(f"tags must be a list, got {type(tags).__name__}")
    return CreatedStory(
        id=_story_id_from_page_id(page_id),
        primary_skill=str(meta.get("title", "")),
        skills=[str(t) for t in tags],
        story_type=str(meta.get("story_type", "")),
        job_title=str(meta.get("job_title", "")),
        situation=paragraphs["Situation"],
        behavior=paragraphs["Behavior"],
        impact=paragraphs["Impact"],
    )


def _story_page_ids(resume_label: str) -> list[str]:
    exp_dir = WikiStore().wiki_root(resume_label) / "experience"
    if not exp_dir.is_dir():
        return []
    return [f"experience/{p.name}" for p in sorted(exp_dir.iterdir()) if p.suffix == ".md"]


def list_stories(resume_label: str) -> tuple[list[CreatedStory], list[str]]:
    """Every readable story page in id order, plus one warning per page skipped."""
    page_ids = _story_page_ids(resume_label)
    pages = WikiStore().read_pages(resume_label, page_ids)
    stories: list[CreatedStory] = []
    warnings: list[str] = []
    for page_id in page_ids:
        try:
            stories.append(story_from_page(page_id, pages[page_id]))
        except WikiPageError as exc:
            message = f"{page_id}: skipped: {exc}"
            logger.warning(message)
            warnings.append(message)
    return stories, warnings


def next_story_id(resume_label: str) -> str:
    highest = 0
    for page_id in _story_page_ids(resume_label):
        match = _STORY_FILE_RE.match(page_id.rsplit("/", 1)[-1])
        if match:
            highest = max(highest, int(match.group(1)))
    return f"story-{highest + 1:03d}"


def save_story(resume_label: str, story: CreatedStory) -> CreatedStory:
    """Write one story page. An identical story (all fields but id) returns the stored one."""
    content = story.model_dump(exclude={"id"})
    existing, _ = list_stories(resume_label)
    for stored in existing:
        if stored.model_dump(exclude={"id"}) == content:
            return stored
    saved = story.model_copy(update={"id": next_story_id(resume_label)})
    timestamp = datetime.now(UTC).isoformat()
    WikiStore().write_page(resume_label, story_page_id(saved.id), story_to_page(saved, timestamp))
```

```python
def _needs_page(resume_label: str, page_id: str) -> bool:
    """True when the page is missing or is an old render without frontmatter."""
    content = WikiStore().read_pages(resume_label, [page_id])[page_id]
    return not content or not content.startswith("---\n")


def migrate_legacy_stories(resume_label: str) -> int:
    """One-time move of stories from accomplishments.json to OKF pages.

    Writes a page only where none exists or the existing one is a pre-OKF
    render (no frontmatter); a page that already has frontmatter is the
    original and is left alone. Then drops the stories from the JSON so this
    never runs twice. Returns the number of pages written.
    """
    store = AccomplishmentsStore()
    legacy = store.legacy_stories()
    if not legacy:
        return 0
    timestamp = datetime.now(UTC).isoformat()
    written = 0
    for record in legacy:
        story = CreatedStory.model_validate(record)
        page_id = story_page_id(story.id)
        if _needs_page(resume_label, page_id):
            WikiStore().write_page(resume_label, page_id, story_to_page(story, timestamp))
            written += 1
    store.drop_legacy_stories()
    logger.info(
        "legacy stories migrated: %d of %d pages written under %s; accomplishments.json now holds onboard_text only",
        written, len(legacy), resume_label,
    )
    return written
```
