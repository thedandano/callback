# Python

**Situation:** Anchor's 6 internal REST APIs for finance and marketing were built ad hoc, with no shared test suite, and reporting bugs reached support every week.

**Behavior:** Rewrote the APIs in Python with a shared routing layer, well-tested code at 90% branch coverage, and a GitHub Actions CI/CD pipeline gating every merge.

**Impact:** Reporting bugs escalated to support dropped 50% quarter over quarter and every API shipped through the same test gate.
