# Open Ledger

**Situation:** Small nonprofits asked for a free double-entry bookkeeping API they could self-host.

**Behavior:** Designed the PostgreSQL schema, wrote the FastAPI endpoints and the migration tooling, and reviewed pull requests from 40 contributors.

**Impact:** The project reached 300 GitHub stargazers and is used by 3 nonprofits in production.
